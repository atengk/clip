# 分类标签词汇表 (Triage Labels)

相关技能使用五个规范的分流分类角色（Canonical triage roles）。本文件将这些角色映射至本仓库 Issue 追踪器所使用的实际标签字符串。

| mattpocock/skills 规范标签 | 仓库实际标签 | 含义说明 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 Issue |
| `needs-info`               | `needs-info`         | 等待提出者提供更多补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 需求规格已明确，可交由离线 Agent 执行 |
| `ready-for-human`          | `ready-for-human`    | 需要人工开发者介入实现 |
| `wontfix`                  | `wontfix`            | 经评估不予处理 |

当技能提及某一角色时（例如“添加 AFK-ready 分流标签”），请使用本表中右侧对应的标签字符串。

您可以按需修改右侧列中的标签名称，以匹配项目实际使用的标签规范。
