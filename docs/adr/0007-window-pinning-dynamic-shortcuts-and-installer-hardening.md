# ADR 0007: 窗口钉住常驻、动态全局快捷键与 NSIS 安装向导加固

## 状态 (Status)
已采纳 (Accepted) - 2026-10-07

## 背景 (Context)
在 `v1.1.0` 与 `v1.1.1` 落地后，社区与重度用户反馈了以下阻断日常交互与分发可靠性的核心痛点：
1. **失焦强隐阻断多窗口对照**：当用户在主程序面板查阅历史或参考代码片段并点击外部第三方窗口时，面板瞬间强制最小化隐藏，无法悬浮常驻作为参考板；
2. **全局热键硬编码与按键冲突**：全局呼出快捷键硬编码为 `Alt + V`，在与部分 IDE、录屏软件或系统快捷键冲突时无法修改；
3. **主面板头部 Row 1 控件拥挤**：头部堆叠 5 组控件，“连贴状态”与底栏重复展示，搜索框横向输入空间被严重压缩；
4. **NSIS 卸载过程空白弹窗**：在 Windows 平台执行卸载时，若检测到应用后台正在运行，弹出一个没有任何文本内容的空白“确定/取消”MessageBox。

## 决策 (Decision)

我们决定实施 **窗口钉住常驻体系 (`WindowPinning`)**、**全局热键动态管理体系 (`GlobalShortcutManager`)** 以及 **安装/卸载向导加固 (`InstallerHardening`)**。

### 1. 窗口钉住置顶与防失焦隐藏 (`WindowPinning`)
- **焦点控制权倒置**：彻底移除 Rust 后端 `lib.rs` 中在 `on_window_event` 处对 `Focused(false)` 强制触发 `window.hide()` 的粗暴逻辑；失焦隐藏逻辑全量移交前端受控；
- **双重受控机制**：
  - **右上角原生钉住按钮**：新增 `📌 钉住` 切换按钮，支持 `Alt + P` 快捷键瞬间切换；激活时呈现主题色高亮与视觉状态反馈；
  - **设置面板行为开关**：在设置面板中提供“失去焦点时自动隐藏窗口”显式开关（持久化至本地存储）；
- **行为保护**：当处于钉住状态或关闭自动隐藏时，点击任何外部程序窗口、桌面或其他任务栏应用，悬浮主面板**绝对不隐藏**，始终保持顶层常驻。

### 2. 主面板头部 Row 1 流线化与空间释放
- **控件精简收敛**：移除顶部重复的“连贴胶囊”与“无痕按钮”，收敛为黄金 4 组（`📋 历史`/`⚡ 短语` 分段模式胶囊、`👁️ 预览`、`📌 钉住`、`⚙️ 设置`）；
- **搜索区域拓宽**：搜索输入框横向可用空间拓宽 **40%**，大幅改善长关键词与短语命令检索视距。

### 3. 全局热键动态管理体系 (`GlobalShortcutManager`)
- **前端可视化录制器**：
  - 设置面板提供按键监听输入框，用户按下实体按键即可自动识别组合键（如 `Ctrl + Shift + V`、`Alt + Space`）；
  - 动态展示当前生效热键的 `kbd` 徽标，并提供“一键恢复默认 (Alt+V)”；
- **修饰键安全规则防御**：
  - 强制校验至少包含一个修饰键（`Ctrl`、`Alt`、`Shift` 或 `Win`），禁止注册孤立字符单键，杜绝全局按键吞噬与系统操作紊乱；
- **动态注销与热重载**：
  - 更改快捷键时，Tauri 后端自动注销原全局热键并即时动态注册新热键；若系统被占用则返回语义化错误；
- **SQLite 存储持久化**：
  - 依托底层 `app_metadata` 表持久化配置，应用重启或随系统开机自启时自动拉取并恢复自定义快捷键。

### 4. NSIS 卸载向导加固与全量宏补齐 (`InstallerHardening`)
- **根因治理**：Tauri 2 配置 `customLanguageFiles` 时，不会自动回退并合入默认的 `SimpChinese.nsh`；一旦自定义 `.nsh` 缺少 `appRunningOkKill`，NSIS 的 `MessageBox MB_OKCANCEL $R2` 将渲染为空白对话框；
- **全量宏补齐**：在 `src-tauri/windows/zh-CN.nsh` 与 `en.nsh` 中全量补齐 Tauri NSIS 要求的全部 27 项语言宏；
- **地道提示**：卸载时检测到 Clip 处于运行状态，自动提示“Clip 正在运行中，点击【确定】将自动关闭进程并继续卸载”，消除空白弹窗缺陷。

## 后果与权衡 (Consequences)

### 正向收益 (Positive)
1. **多任务对照体验大幅提升**：开发者与编辑人员可将 Clip 面板钉在屏幕一侧对照编写，点击目标编辑框输入内容时不退隐；
2. **快捷键生态友好**：彻底解决不同键盘布局与软件快捷键冲突问题；
3. **安装卸载健壮性**：NSIS 自定义语言脚本具备完整的宏覆盖率与地道本地化交互。

### 代价与权衡 (Trade-offs)
- 窗口失焦行为由前端接管后，若前端抛出未捕获异常导致事件循环卡死，可能会失去失焦自隐能力；因此仍保留全局 `Escape` 键顶层逐级退出机制与系统托盘强制隐藏入口作为双重兜底。

## 备选方案对比 (Alternatives Considered)

- **方案 A（仅在 Rust 后端硬编码读取存储开关）**：Rust 后端在 `Focused(false)` 时每次同步查询数据库决定是否隐藏。
  - *否决原因*：跨线程阻塞且无法与前端 React 复杂组件内部的交互（例如正在打开的模态框、正在录制热键）实现细粒度协同。
- **方案 B（全局热键允许单键注册）**：允许用户设置任意单键。
  - *否决原因*：一旦用户误设为普通字母（如 `V`），将导致系统全局无法在任何软件输入该字符，形成严重故障。强制修饰键是保护操作系统正常工作的铁律。
