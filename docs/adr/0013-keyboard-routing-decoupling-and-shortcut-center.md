# 搜索与快速粘贴按键路由解耦及快捷键中心架构决策

## 背景与问题 (Context)

在 Windows 平台日常剪贴板使用中，用户与测试反馈了两项影响操作连贯性的交互体验痛点：

1. **搜索与数字键严重冲突 (Search-Paste Ambiguity)**：
   - 唤出主面板时光标默认聚焦在搜索框内；原先为支持 1~9 快贴，设计了“搜索框为空时单按 `1~9` 直接拦截输入并粘贴第 1~9 项”。
   - 该设计导致致命副作用：**当用户试图搜索以数字开头的内容（如 `100元`、`192.168.1.1`、订单号 `2026...`）时，刚敲下首位数字就会被系统误判为“快速粘贴”而闪退回填，引发灾难性的误贴与挫败感**；
   - 此外，代码中 `Ctrl+1` / `Ctrl+2` 曾被分配给 Tab 切换，与 `Ctrl+1~9` 快速回填存在按键争用。
2. **快捷键生态缺乏透明度与系统化管理 (Shortcut Opacity)**：
   - 设置面板中仅孤立展示了“全局唤起快捷键 (Alt+V)”的输入框；
   - 程序内实际内置了 12+ 种高频按键（如 `Alt+P` 窗口固定、`Shift+Enter` 纯文本粘贴、`Ctrl+K` 操作面板、`Ctrl+Q` 连贴模式、`Ctrl+Z` 撤销、`Space` 抽屉检查等），但全部硬编码且分散在各处，缺乏全景速查与集中管理。

## 方案选型与决策 (Decision)

经过两轮设计推演（`/grill-with-docs`），我们决定实施“**搜索与快贴彻底解耦 + 规范化修饰键直通 + 设置面板升级快捷键中心**”的方案：

### 1. 搜索框与快速粘贴按键路由彻底解耦 (Key Routing Decoupling)
- **搜索框归纯净文本流**：
  - 搜索输入框始终作为 100% 纯粹的文本输入控件：输入任何单字符（包括 `0~9`、字母、符号、空格）绝不予以拦截；
  - 用户输入 `10086`、`192.168` 等数字开头关键字毫无障碍，彻底杜绝误判闪退。
- **快速粘贴 (Fast-Paste) 规范化为 `Alt + 1~9`**：
  - 无论搜索框是空还是包含检索词，任何时刻按下 `Alt+1` ~ `Alt+9`，均直接将前置第 1~9 条目注入系统剪贴板并执行模拟回填（自动隐藏窗口）；
  - 列表左侧键帽徽标更新为直观的 `Alt+1` ~ `Alt+9` 微键帽指引；
  - 释放 `Ctrl+1` / `Ctrl+2`，Tab 模式切换收敛为标准的 `Tab` 键（或在搜索框失焦时切换），消除按键争用。

### 2. 设置面板升级为“快捷键中心 (Shortcut Center)”
- **模块化重构**：将设置面板中的快捷键部分升级为统一的“快捷键中心”，分为两层视图：
  1. **系统级全局热键管理 (OS Global Shortcuts)**：
     - 保留并强化“全局唤醒主面板 (默认 Alt+V)”的动态捕获、录制、格式校验与冲突提示；
  2. **面板交互全景速查卡片 (In-Window Shortcuts Cheat Sheet)**：
     - 采用 Fluent 风格分栏卡片与 `<kbd>` 键盘徽章，全景罗列程序内置的所有按键操作：
       - **粘贴与回填**：`Enter`（立即粘贴）、`Shift+Enter`（强制纯文本无格式粘贴）、`Alt+1~9`（序号极速直贴）；
       - **条目治理**：`Delete`（删除选中项）、`Ctrl+Z`（3秒撤销删除）、`Ctrl+P`（条目置顶/取消置顶）；
       - **视图与交互**：`Alt+P`（窗口常驻固定/取消固定）、`Space`（展开/收起右侧抽屉）、`Ctrl+K`（动作面板 Action Palette）、`Ctrl+Q`（连贴队列 Paste Queue）、`Esc`（逐级退出）。
- **界面微文案对齐**：底部状态栏快捷键提示、Tooltip 与抽屉按钮同步更新为最新键位规范。

## 方案权衡与替代方案对比 (Trade-offs & Alternatives)

| 评估维度 | 方案 A: 纯净搜索 + `Alt+1~9` 修饰键快贴 + 快捷键中心 (本决策采纳) | 方案 B: 双焦点模式 (唤出默认焦在列表，敲字母才切搜索框) | 方案 C: 保留空框单键并增加设置开关 |
| :--- | :--- | :--- | :--- |
| **打字心智模型** | **零意图歧义**：想搜就搜，数字输入绝不误判闪退 | 需按键切换，习惯一唤出就打字的用户会丢失前几个字母 | 依然存在“开开关后输入数字误关窗口”的隐患 |
| **快贴盲打效率** | **极高**：Windows 下 `Alt` 键在空格旁，大拇指配合左手数字极顺手 | 高，但多了一层焦点心智 | 高，但不可靠 |
| **按键生态透明度** | **高**：快捷键中心全景分类呈现，新老用户均清晰可控 | 低，依然分散隐蔽 | 低，设置项进一步碎片化 |
| **实施与维护成本** | 低-中，改动集中在 `handleKeyDown` 与设置 UI | 高，涉及复杂的焦点监听与事件拦截状态机 | 低，但留下逻辑包袱 |

## 架构影响 (Consequences)

- **正面收益**：
  - 根治了剪贴板唤出后无法搜索数字开头内容的顽疾，消除了意外触发粘贴的惊恐感；
  - 快捷键规则全局统一、无二义性，用户肌肉记忆更稳定；
  - 设置面板升级为快捷键中心后，程序的完整交互能力完全显性化，用户可随时查阅。
- **负面成本与注意事项**：
  - 依赖老版本“单按数字 1 直接粘贴”的极少数习惯需平滑过渡至 `Alt+1`；界面的徽标指引需同步清晰化展示。
